# Autonomous Business OS

> **Estado:** Documento de arranque. No representa operaciones verificadas de agentes.

## Propósito

Permitir que una persona dirija varias empresas mediante **objetivos, procesos, agentes y decisiones**, evitando tener que administrar manualmente cada tarea.

## Principios

1. **Business OS administra objetivos empresariales.**
2. **Crobi administra autoridad, agentes y Runs.**
3. Los resultados externos requieren evidencia.
4. El conocimiento canónico vive en Markdown/Git; el índice es reconstruible.
5. Una interfaz clara no debe ocultar errores ni estados desconocidos.

## MVP

- Vista **Ahora** con supervisión por excepción.
- Empresas, proyectos y borradores de misiones locales.
- Docs Markdown con importación local.
- Estado de conexión de Crobi de solo lectura.

## Próxima capacidad

Primer workflow: `solicitud → planificación → ejecución gobernada → PR verificado → aprobación`.
