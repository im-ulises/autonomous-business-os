# Contrato de documentación

## Principios

- Markdown en Git es la fuente canónica.
- Los agentes recuperan solo las secciones autorizadas.
- Las respuestas documentales deben citar archivo, encabezado y versión.
- La consulta no concede permisos de ejecución.
- Las modificaciones propuestas se revisan antes de quedar vigentes.
- Las etiquetas mejoran búsqueda, pero nunca amplían el acceso.
