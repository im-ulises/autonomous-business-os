# Engineering — Playbook

## Objetivo

Producir cambios verificables en proyectos de software.

## Procedimiento objetivo

1. Leer la misión y la documentación permitida.
2. Crear una rama aislada para los cambios.
3. Ejecutar pruebas y revisar resultados.
4. Preparar un pull request con evidencias.
5. Solicitar aprobación antes de integrar o desplegar.

> Este proceso está documentado, pero aún no se ejecuta automáticamente.
