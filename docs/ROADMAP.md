# Roadmap

## v0.1 — Public-safe UI starter
- Responsive console, navigation and local drafts.
- Demo-only projects and missions.
- Markdown reader and Crobi health diagnostic.

## v0.2 — Secure connectivity
- Authentication, per-company data isolation and persistent storage.
- Crobi workspace mappings and read-only Runs/approvals feed.
- Evidence and status reconciliation.

## v0.3 — First governed workflow
- Engineering mission -> approved tools -> verifiable PR.
- Explicit approval before merge/deploy.
- Documentation changes proposed through PR.

Do not ship a public multi-tenant service until identity, data isolation and authority have been tested.
